PRO audiogram interface

Enter measured thresholds in dB HL. This tool records and exports values only; it does not calculate a prescription or safe hearing-aid gain.

What this prototype can and cannot do

Implemented here: mode selection, microphone input selection where supported, audio output selection where supported, Web Audio filtering/EQ/gain/limiting, input visualizer, and audiogram CSV export.

Not implemented: proprietary hearing-aid DSP control, true Bluetooth profile switching, validated ANSD-specific processing, neural-network speech separation, binaural beamforming, verified feedback cancellation, or guaranteed own-voice removal. The web Bluetooth API is not a general-purpose Bluetooth audio-routing API; the operating system may control the actual route.

HearLink development prototype — not a medical device and not a replacement for a prescribed hearing aid, professional fitting, or clinical validation.
